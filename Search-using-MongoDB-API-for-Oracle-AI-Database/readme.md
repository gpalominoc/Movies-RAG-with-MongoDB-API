# Search Using MongoDB API for Oracle AI Database

This draft Oracle LiveLabs workshop provides a 75-minute flow for database developers and platform engineers. Learners can use either a LiveLabs Sandbox or their own OCI tenancy. They install `mongosh` in Cloud Shell and use SQL and the MongoDB API against the same Oracle Autonomous AI Database.

## Workshop contents

- Introduction: search approaches and workshop outcomes
- Get Started: access the LiveLabs Sandbox or own OCI tenancy, install MongoDB Shell, and verify the MongoDB API connection
- Lab 1: load the movie collection and verify SQL, MongoDB API, and ONNX access
- Lab 2: generate stored embeddings, create indexes, and run keyword search
- Lab 3: run semantic and combined searches

The `sandbox` manifest and preview loader are in `workshops/sandbox`. The self-managed tenancy variant is in `workshops/tenancy`.
